🧩 JSON Biçimlendirici & Doğrulayıcı

JSON'u yapıştır; biçimlendir, küçült veya doğrula. API yanıtlarını incelerken ve yapılandırma dosyalarını düzenlerken kullan. Veri tarayıcında işlenir.

En sık JSON hataları

  • Son elemandan sonra virgül bırakmak: [1,2,]
  • Anahtarları tek tırnakla yazmak: JSON yalnızca çift tırnak kabul eder.
  • Yorum satırı eklemek: standart JSON yorum desteklemez.
  • Tırnaksız anahtar: {ad:"x"} yerine {"ad":"x"}.

Verim güvende mi?

Evet. Biçimlendirme ve doğrulama tarayıcının kendi JSON motoruyla yapılır; yapıştırdığın veri hiçbir sunucuya gönderilmez. Token veya kişisel veri içeren API yanıtlarını gönül rahatlığıyla inceleyebilirsin.

Sık sorulan sorular

JSON biçimlendirici verimi kaydeder mi?

Hayır. Tüm işlem tarayıcında yapılır, veri sunucuya gönderilmez.

JSON minify ne işe yarar?

Boşlukları ve satır sonlarını kaldırarak veriyi küçültür; ağ üzerinden gönderim boyutunu azaltır.
