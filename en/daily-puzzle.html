📅 Daily Puzzle

A new 4-digit code every day, the same for everyone. No digit repeats. Can you crack it in 6 guesses?

How to play

The code is a 4-digit number with no repeated digits (for example 4071). Type a guess and press Guess. Each digit changes colour: green means the right digit in the right place, yellow means it is in the code but somewhere else, and grey means it is not in the code. Find the code within six guesses.

Strategy

Use eight different digits across your first two guesses to learn most of the code straight away, then move the yellow digits around. Good players usually solve it in 4–5 guesses.

Is it the same every day?

Yes. The puzzle resets every day at midnight Türkiye time (UTC+3) and everyone plays the same code. Share your result as an emoji grid without giving the answer away.

Frequently asked questions

When does the daily puzzle reset?

Every day at 00:00 Türkiye time (21:00 UTC).

Where is my streak saved?

Only in this device's browser; no sign-up or email needed.

Can a digit repeat?

No, all four digits are different.
