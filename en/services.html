What I do

.NET backend and APIs

REST APIs, microservices and enterprise applications with ASP.NET Core; role-based authorization and Swagger documentation.

  • Migrating legacy .NET Framework projects to modern .NET
  • Code review and architecture advice

Database design and performance

Slow-query analysis, indexing strategy, Query Store, data migration and reporting on SQL Server and Oracle.

  • RFID inventory tracking

Security review
