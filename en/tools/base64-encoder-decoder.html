What is Base64?

Base64 represents binary data using only letters, digits and a few symbols. It is common in email attachments, data URLs and APIs. It is an encoding, not encryption: anyone can decode it.

Frequently asked questions

Is Base64 secure?

No. Base64 is an encoding, not encryption, so it must not be used to protect secrets.

Does it handle Unicode?

Yes. Text is converted to UTF-8 first, so accented letters and emoji round-trip correctly.
