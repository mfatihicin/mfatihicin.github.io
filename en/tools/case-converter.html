Where each case is used

camelCase is common in JavaScript and C#, snake_case in Python and databases, kebab-case in CSS and URLs. A slug is the clean, lower-case part of a URL without spaces or accents.

Frequently asked questions

What is a slug?

A URL-friendly version of a title: 'Coffee Prices 2026' becomes 'coffee-prices-2026'.

Does it handle accents?

Yes. Accented and Turkish letters are converted to plain ASCII for slugs.
