What is a UUID?

A UUID (GUID) is a 128-bit identifier that is unique for all practical purposes. It is used for database keys, file names and API requests. Version 4 UUIDs are fully random.

Frequently asked questions

Can two UUIDs collide?

In theory yes, but the probability is so small that it is ignored in practice.

Can I use them as SQL Server GUIDs?

Yes, they can be stored directly in uniqueidentifier columns.
